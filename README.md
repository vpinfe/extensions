# VPinFE Official Extensions

These are the extensions the VPinFE team supports. You can install them from **System > Extensions** in VPinFE.

## The list
- **VPinPlay**: Players, their pictures and accounts, and guests joining from the Remote.
- **Library Importer**: Imports your tables and settings from other front ends.

## Adding your extension
Open a pull request that adds your extension to the list, and the VPinFE team will review it. Your extension needs to:

1. **Respect creators.** Get tables, media and other people's work only from where their creators share them, and follow those sites' rules. Don't download or share them in bulk.
2. **Have a home and an owner.** Keep it in a public repository (your own is fine), with someone named to look after it.
3. **Use only the documented extension features**, and say what it does.
4. **Work on every system VPinFE runs on**, or say which ones it doesn't. Each dependency you list needs a download for every system you claim.
5. **Have a license that lets us keep it working** if you stop maintaining it.

## If an extension is removed
VPinFE marks it Unofficial and turns it off the next time it checks the list. You can turn it back on yourself, or uninstall it.

## Other extensions
You can still add other extensions by putting them in VPinFE's extensions folder. VPinFE marks them Unofficial and asks you to confirm before turning one on. We can't give support to a setup that runs unofficial extensions.
